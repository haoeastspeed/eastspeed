Code Signing Policy · East Speed (东方神速)

免费代码签名 / Free code signing

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

本项目的正式发布版本（DongFangSpeed.exe 等可执行文件）由 SignPath Foundation 提供的免费代码签名证书进行签名。签名私钥在 SignPath 的硬件安全模块（HSM）中生成与保管， 签名过程把公开源码仓库与发布的二进制文件可验证地关联起来： 用户可据此确认所运行的程序确由本仓库的源码自动构建、且发布后未被篡改。

Free code signing is provided by SignPath.io, with the certificate issued to and owned by SignPath Foundation. Each signature cryptographically links the published binary to an automated, verifiable build from this public repository.

团队角色与成员 / Team roles

East Speed is currently maintained by a single maintainer, who holds the following roles. Every change is reviewed before it reaches a release branch, and every signing request is manually approved.

Authors / Committers（可提交源码）haoeastspeed（仓库维护者 / repository owner）
Reviewers（代码审查）haoeastspeed — 所有变更（含外部 Pull Request）在合入发布分支前均由维护者审查。
All changes, including external pull requests, are reviewed by the maintainer before merging.
Approvers（签名审批）haoeastspeed（Repository Owners）— 每次代码签名请求都由维护者在 SignPath 后台人工批准。
Every signing request requires manual approval by the repository owner in SignPath.

可复现的受信构建 / Verifiable automated builds

  • 所有待签名的发布二进制都由 GitHub Actions 从公开仓库 haoeastspeed/eastspeed 的源码自动构建，构建脚本与 CI 配置本身也在该仓库中（.github/workflows/build.yml）。
  • 构建过程在干净的 Windows Runner 上完成：安装依赖 → 运行单元/端到端测试 → PyInstaller 打包 → 执行 --selftest 自检 → 产出构件，全过程公开可查。
  • 每个发布版本的产品名（East Speed）与产品版本号在同一次构建中保持一致（写入可执行文件的版本资源）。
  • 不会上传本地编译的二进制去签名；签名仅接受由受信 CI 从源码构建的产物。

上游开源组件 / Upstream open-source components

安装包中随附 Python、Qt/PyQt、libtorrent 等第三方开源运行库与依赖。这些上游程序库由其各自的 开源项目发布，不使用本项目的签名证书签名；本项目仅对由自有源码构建的主程序签名。 完整依赖与许可证见仓库的 requirements.txt 与 LICENSE。

隐私与系统变更 / Privacy & system changes

程序不会在未经用户请求的情况下向其他系统传输信息；下载、媒体接管、更新检查等网络行为均由用户主动发起或可在设置中关闭。 详见 隐私政策 / Privacy Policy。

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. Optional features such as browser integration and update checks can be disabled in Settings.

通过安装包安装的版本可在 Windows「应用与功能」中卸载；便携版与单文件版为绿色程序，删除文件即可移除。
