关于数字签名（重要）

东方神速当前为早期发布版本，暂时尚未购买或配备 Windows 代码签名证书。这是个人开发者项目在起步阶段的常见情况：OV/EV 代码签名证书每年需要数百至数千元费用。

首次运行时，Windows SmartScreen 可能弹出「Windows 已保护你的电脑」蓝色提示。这是所有未签名程序的正常现象，并非本软件有病毒。点击「更多信息」→「仍要运行」即可。

我们计划在用户量与收入达到一定规模后，购买正规 OV/EV 代码签名证书为后续版本签名，届时 SmartScreen 提示将自动消失。

如何校验下载文件是否完整、未被篡改

为便于你确认下载到的就是官方发布的文件，下面提供最新单文件版 EastSpeed.exe 的 SHA-256 校验值。下载完成后，可在 PowerShell 中运行：

Get-FileHash EastSpeed.exe -Algorithm SHA256

将输出结果与下表比对，完全一致即说明文件完整、未被第三方篡改：
