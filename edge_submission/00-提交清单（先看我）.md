> 目标：把浏览器扩展「东方神速 下载接管」（Manifest V3，v1.2.0）提交到 **Microsoft Edge 加载项（Edge Add-ons）**，实现和 IDM 一样的**商店正式签名扩展**——用户从商店一键安装、原 Edge 入口永久生效、无开发者模式警告、可自动更新。

> 依据：Microsoft Learn 官方文档《Publish a Microsoft Edge extension》《Register as a Microsoft Edge extension developer》（2025-12 更新）。**Edge 扩展上架免费、无注册费、无年费。**

## 二、提交全流程（Partner Center 8 步）

入口：<https://partner.microsoft.com> → 用 Microsoft 账号（或 GitHub 账号）登录 → 进入 **Edge** 工作区 → **Create new extension**。

| 步骤 | 页面 | 要做的事 | 材料出处 |
|---|---|---|---|
| 0 | 注册开发者账号 | 选**个人**或**公司**（见第三节，重要且不可改）；免费 | 需你本人操作 |
| 1 | Upload package | 上传 `东方神速-Edge商店版-1.2.0.zip` | ✅ 已备 |
| 2 | Availability（可用性） | Visibility 建议先 **Hidden**（仅持链接可装，便于内测）或 **Public**（公开可搜索）；Markets 默认全部市场 | 你决定，建议见下 |
| 3 | Properties（属性） | Category 选 **Productivity（效率/生产力）**；Website、Support contact 选填但建议填 | `01` 已给文案 |
| 4 | Privacy（隐私）⭐最关键 | 填单一用途、逐权限理由、远程代码选 **No**、数据使用勾选、**隐私政策 URL（必填）** | `02` + 托管后的 `privacy-policy.html` |
| 5 | Store Listings（商店一览） | 每种语言填：详细描述（250–10000 字符）、Logo（300×300）、短描述（取自 manifest，只读）、宣传图、截图、搜索词 | `01` + `assets/` |
| 6 | Notes for certification | 粘贴测试说明（**务必说明这是配套桌面程序的扩展，否则易被判“不工作”而拒审**） | `03` |
| 7 | Publish → 等待审核 | 审核最长 **7 个工作日**，通过后状态变 **In the Store** | — |

> 页面若报 `correlationId` 错误：清缓存/cookie、用 InPrivate 窗口或换浏览器重试（官方已知问题）。

## 三、需要你本人拍板/提供的 6 件事（AI 无法替代）

1. **开发者账号类型（注册后国家/地区、账号类型均不可更改）**
   - **个人账号**：验证快（仅校验发布者显示名是否可用），用个人 Microsoft/GitHub 账号即可。**建议首版选个人，最快上架。**
   - **公司账号**：验证 **几天到几周**；必须用**组织注册邮箱**（**不接受 Gmail/QQ/163/Outlook 等网页邮箱**，你可用 `name@your-company.com`）；需填公司审批者姓名/邮箱/电话，可能接到微软验证电话，可能要上传营业执照/DUNS/水电单等法律文件。适合以后以“凌云光”主体正式发行。
   - 发布者显示名 ≤ 50 字符（如“东方神速”“凌云光技术”），需确保**名称/商标有权使用且未被占用**。

2. **隐私政策必须是一个可公开访问的 URL（硬性要求，因扩展用到 cookies + 全站访问）**
   - 免费方案：把 `privacy-policy.html` 放到 **GitHub Pages / Gitee Pages**（得到一个 `https://xxx.github.io/...` 链接）；或放到公司官网。
   - 没有这个 URL，第 4 步无法通过。AI 已把网页内容做好，你只需上传托管并把链接填进去。

3. **官网 / 支持联系方式（选填但强烈建议）**
   - Website 必须是**你自己的页面**，不能填商店列表页；Support contact 可填邮箱（如 `haodongfang@hotmail.com`）或支持页 URL。

4. **可见性**：建议先 **Hidden** 拿到链接自己装好测一遍，确认无误后再在后台改 **Public** 公开。

5. **语言**：本材料**首版按“简体中文”提交**（manifest 名称/描述为中文硬编码，商店识别为 1 种语言，这是正确做法，**切勿手滑加 `default_locale`**，历史上曾因此加载失败）。若要**中英双语**全球发行，需把 manifest 改成 `__MSG_extensionName__/__MSG_extensionDescription__` + `default_locale` + `_locales/` 并回归测试——属于代码改动，可作为下一版，届时再找我。

6. **真机补 2 张截图（可选）**：商店截图最多 6 张，已用程序自动生成 4 张；建议你在真实 Edge 里再截：①网页视频上的**悬浮下载按钮**；②播放视频后 popup 里**媒体嗅探列表有内容 / 已连接**的样子。尺寸必须严格 **1280×800 或 640×480**。

> 账号注册、协议同意、隐私 URL 托管、最终 Publish 必须由你本人登录操作；其余可填内容本包已全部写好。

## 四、提交前自查（合规要点，已替你核对）

- ✅ Manifest V3，**无远程代码**：全部脚本随包提供，无 `eval` / `new Function` / 远程 JS 加载 / `executeScript` 注入远程代码（第 4 步选 **No, I am not using remote code**）。
- ✅ **无任何远程服务器/后端/统计/账号**：扩展所有网络请求只发往用户本机 `http://127.0.0.1:<port>`（桌面程序桥接），数据不出本机、不上互联网。
- ✅ 权限遵循最小化，且每个权限都在 `02` 中给出了逐条理由。
- ✅ 包内 `manifest.json` 位于 zip 根目录，含全部图标与脚本。
- ⚠️ **最大拒审风险**：审核员若没装桌面程序，popup 只会显示“未连接”，可能被误判为“扩展无法工作”。`03` 的测试说明已专门处理这一点（英文说明 + 测试步骤），**请务必原样粘贴到 Notes for certification**。
- ⚠️ 扩展**不支持 DRM 保护内容**（Widevine/PlayReady/FairPlay/加密 HLS），文案已如实声明，避免“功能与描述不符”。
