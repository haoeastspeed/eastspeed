## 1. Single Purpose Description（单一用途描述）

**中文：**
```
本扩展是 Windows 桌面下载管理器「东方神速（East Speed）」的浏览器接管组件，具有唯一且明确的用途：把用户在浏览器中触发的文件下载、网页媒体（mp4/m3u8/mp3 等）以及普通未加密 Blob，转交给运行在用户本人电脑上的「东方神速」桌面程序进行多线程加速与断点续传下载。扩展不独立提供下载功能、不包含云端服务，仅在浏览器与本机程序（127.0.0.1 回环地址）之间传递下载所需信息。
```

**English:**
```
This extension is the browser hand-off component of the Windows desktop download manager “East Speed”. It has one single, narrow purpose: to hand file downloads, web media (mp4/m3u8/mp3, etc.), and ordinary unencrypted Blobs from the browser over to the East Speed desktop app running on the user’s own computer for multi-connection accelerated downloading with resume support. The extension does not download files on its own and has no cloud service; it only passes download information between the browser and the local app over the 127.0.0.1 loopback address.
```

## 2. Permission justification（逐权限理由）

### `downloads`
```
用于监听浏览器下载创建事件（chrome.downloads.onCreated），在用户点击下载链接时取消浏览器默认的单线程下载，并把该下载任务转交给本机「东方神速」程序，以启用多线程加速与断点续传。仅在用户开启“自动接管”后生效。
```
Used to listen for download-creation events so that, when the user clicks a download link with takeover enabled, the browser’s default single-connection download is canceled and the task is handed to the local East Speed app for multi-connection, resumable downloading.

### `cookies`
```
用于读取“被下载链接所在网站”的 Cookie（chrome.cookies.getAll 按具体 URL 查询），并把它随下载请求发送给本机桌面程序，使程序能够下载需要登录态/会话的资源（例如用户已登录网站中的文件）。Cookie 仅发送到 127.0.0.1 本机程序，不发送到任何远程服务器，扩展不保存、不上传 Cookie。
```
Used to read the cookies of the specific site whose file is being downloaded (queried by URL via chrome.cookies.getAll) and pass them to the local desktop app so it can download resources that require a login session. Cookies are sent only to 127.0.0.1 on the local machine, never to any remote server, and are not stored or uploaded by the extension.

### `webRequest`
```
以只读、非阻塞方式监听页面的网络请求（chrome.webRequest.onBeforeRequest，未使用 blocking），用于实时嗅探页面正在加载的 mp4/m3u8/mp3 等媒体地址并展示在扩展面板中。扩展不修改、不拦截、不重定向任何请求，也不记录或上传浏览历史。
```
Used in read-only, non-blocking mode (onBeforeRequest, without blocking) to detect media URLs such as mp4/m3u8/mp3 loaded by the current page and list them in the popup. The extension never modifies, blocks, or redirects requests and does not record or upload browsing history.

### `storage`
```
用于在用户本机保存扩展自身的少量设置，例如接管/嗅探开关、本机桥接端口、令牌以及本页面检测到的媒体列表。数据仅保存在浏览器本地存储中。
```
Used to store a small amount of the extension’s own settings locally, such as the takeover/sniffing toggles, the local bridge port and token, and the media list for the current page. Data stays in browser local storage.

### `notifications`
```
用于在下载被接管、下载完成等时机向用户显示本地浏览器通知。
```
Used to show local browser notifications when a download is taken over or completed.

### Host permission：`<all_urls>`
```
扩展需要在任意网页上注入内容脚本，以实现：在视频页面显示悬浮“下载视频”按钮、钩住页面通过 URL.createObjectURL 生成的普通 Blob、读取当前页面的下载/媒体地址。扩展仅在用户主动使用相关功能时读取页面信息，且这些信息只发往本机程序。不读取表单、密码、支付或私信内容。
```
Required to inject content scripts on any website in order to show the floating “Download video” button on video pages, hook ordinary Blobs created via URL.createObjectURL, and read the current page’s download/media addresses. Page information is read only when the user actively uses these features and is sent solely to the local app. The extension does not read forms, passwords, payment data, or private messages.

### Host permission：`http://127.0.0.1/*` 与 `http://localhost/*`
```
这两个本机回环地址用于扩展与运行在用户自己电脑上的「东方神速」桌面程序通信（配对 /ping、/pair，提交任务 /add、/add-blob）。回环流量不经过局域网或互联网。
```
These loopback hosts are used to communicate with the East Speed desktop app running on the user’s own computer (pairing /ping and /pair; submitting tasks via /add and /add-blob). Loopback traffic never leaves the machine.

## 3. Are you using remote code?（是否使用远程代码）

**选择：`No, I am not using remote code`（否）。**

依据（自查结论，无需粘贴）：本扩展为 Manifest V3，所有 JavaScript 均随包提供；代码中不存在 `eval`、`new Function`、远程脚本加载、`importScripts` 远程地址或 `chrome.scripting.executeScript` 注入远程代码，service worker 不加载任何远程托管代码。MV3 本身也禁止远程代码。

## 4. Data usage（数据使用声明）

**“你计划收集哪些用户数据”——建议勾选：**
- ☑️ **网页内容 / Website content**（读取下载链接、媒体 URL、普通 Blob 二进制）
- ☑️ **身份验证信息 / Authentication information**（为下载需登录资源而读取该站点 Cookie）

**不勾选**：位置、财务与支付信息、个人通信、健康、联系人等（扩展均不涉及）。
> `webRequest` 仅在页面打开期间**实时、本地**嗅探媒体请求，不持久化、不上传浏览历史，因此不按“浏览历史收集”勾选；如后台审核要求补充，可在备注中引用第 2 节 `webRequest` 理由。

**“我证明以下披露属实”（certify）复选框——全部勾选：**
- ☑️ 收集和使用数据的描述准确、完整；
- ☑️ 不会将数据出售给第三方，不用于广告或营销目的；
- ☑️ 不会将数据用于与扩展核心功能无关的用途；
- ☑️ 不会用于信用评估或放贷；
- ☑️ 数据处理符合隐私政策与 Edge 加载项开发者政策。

**可在数据说明框补充（中文）：**
```
本扩展不设置任何远程服务器。所有下载链接、Cookie、Referer 与媒体二进制数据仅在浏览器与用户本机 127.0.0.1 上运行的「东方神速」桌面程序之间传输，不离开用户电脑、不上传互联网、不与任何第三方共享，也不用于广告或分析。
```
English: The extension operates no remote server. All download URLs, cookies, Referer headers, and media binary data are exchanged only between the browser and the East Speed desktop app on 127.0.0.1 of the user’s own machine; data never leaves the device, is not uploaded to the Internet, is not shared with third parties, and is not used for advertising or analytics.
