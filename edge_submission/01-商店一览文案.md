### Description（详细描述，必填，250–10000 字符）
```
「东方神速 下载接管」是 Windows 桌面下载管理器「东方神速（East Speed）」的官方浏览器配套扩展。安装并运行免费的桌面程序后，本扩展会把浏览器里的下载任务与网页媒体，一键转交给桌面程序进行多线程加速与断点续传下载，体验对标 IDM。

【工作方式】
本扩展本身不负责写盘和联网下载，它是浏览器与本机「东方神速」桌面程序之间的桥梁：扩展只与用户本机回环地址 127.0.0.1 通信，不经过任何远程服务器，不注册账号，不收集、不上传任何用户数据。

【主要功能】
1. 自动接管浏览器下载：在网页中点击任意文件下载链接时，自动取消浏览器自带的单线程下载，弹出桌面程序的下载确认窗口，由「东方神速」使用最多 16 个并发连接分段加速下载，并支持断点续传、失败自动重试与卡死连接自动切换。
2. 网页媒体嗅探：自动识别当前页面正在请求的 mp4、m3u8/HLS、mp3 等媒体地址并在扩展面板中列出，点击即可下载；在线视频页面还会显示悬浮“下载视频”按钮。
3. m3u8 / HLS 视频下载：检测到 HLS 流媒体时转交桌面程序自动下载全部分片并合并为完整视频文件。
4. Blob 流接管（实验性）：可保存页面通过 blob: 方式生成、且尚未释放的普通未加密 Blob 对象。
5. 手动新建下载：在扩展面板粘贴任意 http/https（含 m3u8）链接即可下载。
6. 自动配对：扩展与桌面程序通过本机端口自动配对，无需手动填写令牌；连不上时也可在桌面程序设置中复制令牌手动填写。
7. 完成通知：下载接管与完成时通过浏览器通知提示。

【转交给桌面程序后可获得的能力】
多连接加速与断点续传、按文件类型自动分类、实时速度曲线、计划任务与全部完成后关机/休眠、MD5/SHA-1/SHA-256 校验、HTTP/HTTPS/FTP/FTPS、BT 种子与磁力链接、整站资源抓取、下载完成杀毒调用、磁盘空间检查与真实占盘式预分配、代理（含 NTLM/PAC）等。

【隐私与安全】
所有链接、Cookie、Referer 与媒体数据仅在浏览器与你本机运行的「东方神速」程序之间传输，不会发送到任何云端或第三方；扩展不含远程代码、不含广告、不含统计与跟踪脚本。

【说明】
· 需要免费的 Windows 桌面程序「东方神速」配合使用，未运行时扩展面板显示“未连接”属正常现象。
· 出于版权与版权保护技术的限制，本扩展不下载受 DRM 保护的内容（如 Widevine/PlayReady/FairPlay 及加密 HLS）。
· 请仅下载你有权获取的内容，并遵守所在网站的条款与当地法律法规。
```

### Description (250–10,000 characters)
```
“East Speed Download Integration” is the official browser companion extension for the Windows desktop download manager “East Speed”. With the free desktop app installed and running, the extension hands download tasks and web media from your browser over to the desktop app for multi-connection accelerated downloading with resume support — an experience comparable to IDM.

How it works
The extension itself does not write files or download data. It is a bridge between your browser and the local East Speed desktop app. It communicates only with the loopback address 127.0.0.1 on your own computer. There is no remote server, no account, and no collection or upload of your data.

Key features
1. Automatic download takeover: when you click a file download link, the browser’s built-in single-connection download is canceled and the desktop app’s confirmation dialog opens. East Speed then downloads the file using up to 16 concurrent connections (segmented acceleration), with resume support, automatic retries, and automatic failover for stalled connections.
2. Web media sniffing: detects mp4, m3u8/HLS, and mp3 media requested by the current page, lists them in the popup, and shows a floating “Download video” button on online video pages.
3. m3u8 / HLS video download: when HLS streams are detected, the desktop app downloads all segments and merges them into a complete video file.
4. Blob takeover (experimental): saves ordinary, unencrypted Blob objects that the page created via blob: and has not yet revoked.
5. Manual download: paste any http/https (including m3u8) link in the popup to start a download.
6. Automatic pairing: the extension pairs with the desktop app over the local port automatically; a manual token is available in the desktop settings if needed.
7. Notifications for takeover and completion.

Capabilities provided by the desktop app after handoff
Multi-connection acceleration and resume, automatic categorization by file type, real-time speed graph, scheduler and shutdown/hibernate when all downloads finish, MD5/SHA-1/SHA-256 verification, HTTP/HTTPS/FTP/FTPS, BitTorrent and magnet links, limited site grabbing, post-download antivirus invocation, disk-space checks and real disk pre-allocation, and proxies (including NTLM/PAC).

Privacy & security
URLs, cookies, Referer headers, and media data are exchanged only between the browser and the East Speed app running on your own machine, and are never sent to any cloud or third party. The extension contains no remote code, no ads, and no analytics or tracking.

Notes
· Requires the free Windows desktop app “East Speed”. When it is not running, the popup correctly shows “Not connected”.
· DRM-protected content (Widevine/PlayReady/FairPlay and encrypted HLS) is not supported.
· Please download only content you have the right to obtain, and respect website terms and applicable laws.
```
