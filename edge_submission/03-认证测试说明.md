# 03 · Notes for Certification 认证测试说明（直接粘贴）

> 对应提交最后一步 **Notes for certification** 文本框。
> 这是降低拒审率最关键的一段：必须让审核员明白**这是配套桌面程序的扩展**，否则只装扩展时 popup 显示“未连接”，极易被误判为“无法工作”。
> 建议粘贴英文版（审核更通用），中文版留档。

---

## English（推荐粘贴）

```
IMPORTANT - Companion of a desktop app. No credentials/accounts needed; only the free desktop app below is required to fully test.

This is the browser hand-off component of the free Windows download manager "East Speed" (东方神速). It does NOT download files itself and has no cloud service; it only talks to the companion desktop app over loopback 127.0.0.1 (default port 8765). Without the desktop app, the popup correctly shows a red "Not connected" state - this is expected, not a failure.

Full test (Windows):
1. Download/run the free desktop app (no install, no account): release page https://github.com/haoeastspeed/eastspeed/releases/tag/v1.0.0 - direct file https://github.com/haoeastspeed/eastspeed/releases/download/v1.0.0/DongFangSpeed.exe
2. Start it; it listens on 127.0.0.1:8765 and the popup then shows "Connected" automatically (auto-pairing, no token).
3. Takeover: click a normal file download link; the native download is canceled and the desktop app shows a confirm dialog; Start downloads with up to 16 connections plus resume.
4. Media: play an MP4 or HLS(m3u8) video; the popup lists it and a floating "Download video" button appears. You can also paste an http/m3u8 URL in the manual box.
5. Blob (experimental): plain unencrypted blob: objects are listed while the page holds them.

No accounts, ads, analytics, or remote code (Manifest V3; no eval or remote scripts); URLs/cookies/Referer/media go only to 127.0.0.1. Permissions: downloads = hand off; cookies = send the site's cookies to the LOCAL app for login-required files; webRequest = read-only media sniffing; storage/notifications = settings and notices; <all_urls> = inject the video button; 127.0.0.1/localhost = local app. DRM content (Widevine/PlayReady/FairPlay, encrypted HLS) is intentionally unsupported. First submission, version 1.2.0. If the desktop app cannot be installed, please review the popup UI and toggles; "Not connected" in that case is expected.
```

## 中文（留档 / 中文审核员）

```
重要——本扩展是桌面程序的配套（companion）扩展，测试前请先阅读。

本扩展是免费 Windows 桌面下载管理器「东方神速（East Speed）」的浏览器接管组件，本身不执行下载、无云端服务，仅通过本机回环地址 127.0.0.1（端口可配，默认 8765）与桌面程序通信。

未安装桌面程序时的预期表现：安装后工具栏弹窗右上角显示红色“未连接”，各开关正常显示。这是配套桌面程序未运行时的正确、预期状态，并非故障。

完整测试方法（需 Windows）：
1. 从官方发布页 https://github.com/haoeastspeed/eastspeed/releases/tag/v1.0.0 下载免费桌面程序「东方神速」（单文件直链 https://github.com/haoeastspeed/eastspeed/releases/download/v1.0.0/DongFangSpeed.exe），无需安装，直接运行。
2. 启动桌面程序，它会监听 127.0.0.1:8765，无需注册登录。
3. 打开扩展弹窗，状态自动变为“已连接”（通过 /pair 自动配对，无需令牌）。
4. 接管测试：在网页点击任意普通文件下载链接，浏览器原生下载被取消，桌面程序弹出确认窗，点“开始下载”即以最多 16 连接分段下载，支持断点续传。
5. 媒体嗅探：打开播放 MP4 或 HLS(m3u8) 的页面并开始播放，弹窗“本页检测到的媒体”中会列出该媒体；HTML5 视频上还会出现悬浮“下载视频”按钮。
6. 手动下载：在弹窗手动框粘贴任意 http/https 或 m3u8 链接，点下载。
7. Blob（实验性）：页面暴露的普通未加密 blob: 对象会列在 Blob 区，可在页面仍持有该对象时保存。

测试说明：
- 无需任何测试账号、密码或登录。
- 扩展无远程服务器、无广告、无统计、无远程代码（Manifest V3，无 eval、无远程脚本）；URL/Cookie/Referer/媒体数据仅与本机 127.0.0.1 交互。
- 权限用途：downloads=取消原生下载并接管；cookies=把下载站点 Cookie 交本机程序以下载登录资源；webRequest=只读非阻塞媒体嗅探；storage=本地设置；notifications=接管/完成通知；<all_urls>=在任意站点注入悬浮按钮与 Blob 钩子；127.0.0.1/localhost=与本机程序通信。
- 受 DRM 保护内容（Widevine/PlayReady/FairPlay、加密 HLS）按设计不支持。
- 本次为首次提交，版本 1.2.0。
若认证环境无法安装桌面程序，请评估弹窗界面、开关、手动下载框以及“不存在任何外部网络连接”；该环境下显示“未连接”属预期。
```
