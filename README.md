# 东方神速 East Speed

**东方神速（East Speed）** 是一款面向 Windows 的高速、轻量下载管理器，对标 IDM，支持多连接动态分片、断点续传、浏览器接管、m3u8/HLS 视频下载、BT/磁力、FTP/FTPS 等。

## 版本说明（两个版本）

东方神速提供两个版本，**功能完全一致**，区别仅在于授权形态：

| | 免费试用版（本仓库） | Pro 授权版 |
|---|---|---|
| 仓库 | haoeastspeed/eastspeed | haoeastspeed/eastspeed-pro |
| 授权 | 免费，自首次启动起 **1 年**内全功能无限制 | 需激活授权，无试用期 |
| 授权/支付入口 | 无（已隐藏） | 启动需在线/离线激活 |
| 到期处理 | 1 年期满后提示授权 | 按授权期限 |
| 适用人群 | 个人用户、免费分享 | 付费用户 / 内部使用 |

- **普通用户请直接在本页面（免费试用版）下载。**
- 需要 Pro 授权版请前往 [haoeastspeed/eastspeed-pro](https://github.com/haoeastspeed/eastspeed-pro)。
